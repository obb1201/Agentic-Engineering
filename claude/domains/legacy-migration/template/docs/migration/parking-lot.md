# Parking Lot

Open questions and blockers that need a human. The agent adds entries and the human answers them. Answered business-rule questions move to `business-rules.md` or `decision-log.md`.

## Template

```
## P<number>: <short title> [question | blocker] [open | answered]

- Slice:
- Source (file:line):
- What I found:
- Options:
- For blockers, what I tried (up to 3 attempts):
- Answer (human):
```
