# Open Questions

Questions and blockers waiting for an expert. The agent adds entries. Answers come back through interviews (see the `kt-interview` skill), so they can be cited.

## Template

```
## Q<number>: <short title> [question | contradiction | blocker] [open | answered]

- Document:
- What I need to know:
- What I found (sources):
- Ask: <expert or role>
- For blockers, what I tried (up to 3 attempts):
- Answer: see I<nn>
```
