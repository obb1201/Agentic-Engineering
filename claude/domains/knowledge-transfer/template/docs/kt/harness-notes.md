# Harness Notes

Notes on how the **harness** performed, for improving it later. This file is not handed over.

Add a line whenever a human corrects, unblocks or redirects the agent, a hook blocks something, or anything surprising happens. Both the human and the agent may add lines.

When a document is approved, or the handover ends, copy the lessons into the experiment log of the harness repo. **Remove client, vendor and system names, code and file paths first.**

## Template

```
- YYYY-MM-DD | <document or phase> | <intervention | hook | surprise> | what happened | which harness piece it points to (tools, information, permissions, instructions, checking work, limits, failure handling)
```
